# Hearts Arc Jewelry Shop

Static multi-page jewelry storefront built for GitHub Pages hosting.

## Pages

- `index.html` - homepage
- `gallery.html` - product gallery
- `details.html` - product detail page
- `cart.html` - shopping cart page
- `about.html` - brand/about page
- `support.html` - FAQs, shipping, returns, care, tracking, and concierge support
- `wishlist.html` - saved favorites and wishlist page
- `profile.html` - profile/account overview page

## Hosting

This site is plain HTML, CSS, and JavaScript, so it can be published directly with GitHub Pages from the repository root.
